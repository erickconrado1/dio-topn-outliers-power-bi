# TOPN & Outliers — Power BI

## Sobre o projeto

Projeto desenvolvido como parte da formação Power BI Analyst da DIO, com foco na apresentação visual de indicadores comerciais utilizando a base Financial Sample.

## Objetivo

Apresentar uma proposta de dashboard gerencial para análise de vendas, lucros e desempenho de produtos, com destaque para rankings e identificação de produtos relevantes para a tomada de decisão.

## Indicadores e análises

- Vendas totais;
- Lucro total;
- Unidades vendidas;
- Comparação de desempenho entre produtos;
- Ranking dos produtos por lucro;
- Análise dos produtos por país;
- Visualização de possíveis outliers e diferenças de desempenho.

## Visualização do dashboard

O arquivo `dashboard_TOPN_Outliers.png` apresenta a proposta visual da página TOPN & Outliers, seguindo a identidade visual do relatório de referência.

**Observação:** a imagem é uma representação estática. Os indicadores e gráficos devem ser interpretados conforme o nível de validação dos dados realizado para esta versão.

## Ferramentas e tecnologias

- Microsoft Power BI — referência de visualização e análise;
- Financial Sample — base de dados de referência;
- GitHub — versionamento e publicação dos materiais do projeto.
